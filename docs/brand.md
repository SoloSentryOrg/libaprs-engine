# Brand Assets

![libaprs-engine logo](assets/brand/logo.svg)

## BLUF

- Final direction: `5A-1 Pulse Bracket`.
- The mark represents a strict parser boundary around a clean radio signal.
- Use `2E0MZA>APRS:>hello` as the sample packet in project-owned branding.
- Keep branding minimal, technical, and documentation-focused.
- Do not use mascots, cyberpunk styling, fake badges, or stock radio imagery.

## Assets

- [`mark.svg`](assets/brand/mark.svg): compact signal mark.

## Usage

- Use the mark when space is constrained.
- Use the wordmark in documentation pages, presentations, and release notes.
- Use the README banner only at the top of repository-facing documentation.
- Use the social preview source for GitHub repository social-card export.
- Preserve the raw-byte, fail-closed, protocol-first message in any future
  brand graphic.
