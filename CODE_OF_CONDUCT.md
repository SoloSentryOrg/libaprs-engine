# Code Of Conduct

## BLUF

- Be respectful, specific, and constructive.
- Keep technical disagreement focused on evidence, code, and project goals.
- Do not harass, threaten, demean, or exclude people.
- Report serious conduct issues privately to the repository owner.
- Maintainers may remove content or access when behavior is unsafe or abusive.

## Expected Behavior

Participants are expected to:

- Use welcoming and inclusive language.
- Respect different experience levels and backgrounds.
- Give and receive technical feedback in good faith.
- Keep issue and pull request discussion focused on the project.
- Avoid publishing private packet data, credentials, operator details, or precise
  private locations in public project spaces.

## Unacceptable Behavior

Unacceptable behavior includes:

- Harassment, threats, personal attacks, or discriminatory language.
- Sexualized language or imagery.
- Sustained disruption of project discussion.
- Publishing another person's private information without explicit permission.
- Submitting abusive, misleading, or knowingly unsafe security reports.
- Any other conduct that a maintainer reasonably determines is harmful to the
  project or its community.

## Enforcement

Maintainers may take proportionate action, including:

- Asking for clarification or a change in tone.
- Editing or removing comments, issues, or pull requests.
- Temporarily or permanently restricting participation.
- Reporting severe abuse to GitHub or relevant authorities.

Enforcement decisions should prioritize participant safety, project integrity,
and a clear technical record.

## Reporting

For conduct issues, contact the repository owner through GitHub. For security
vulnerabilities, use GitHub private vulnerability reporting when it is available
for this repository.
